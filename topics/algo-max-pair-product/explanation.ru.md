# Наибольшее произведение двух чисел

> **Режим практики.** Это *challenge*-тема: реализуйте метод в `Solution.java`,
> нажмите **«Запустить тесты»**, и скрытый харнес прогонит ваш код на наборе
> кейсов. Миссия зачтена, когда все зелёные.

## Задача

Дан массив целых чисел (длина ≥ 2) — верните **наибольшее произведение любых двух
из них**.

## Ловушка: отрицательные

Хочется просто взять два наибольших значения. Но два больших **отрицательных**
числа дают большое **положительное**:

```
{-10, -3, 1, 2}  ->  -10 * -3 = 30   (обгоняет 1 * 2 = 2)
```

Поэтому ответ — это бо́льшее из:

- произведения **двух наибольших** значений и
- произведения **двух наименьших** (самых отрицательных) значений.

## Оптимальное решение — один проход, O(n)

Сортировать не нужно. Отслеживайте два наибольших и два наименьших значения за один
проход, затем сравните два кандидата:

```java
int max1 = Integer.MIN_VALUE, max2 = Integer.MIN_VALUE; // два наибольших
int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE; // два наименьших
for (int n : nums) {
    if (n > max1) { max2 = max1; max1 = n; }
    else if (n > max2) { max2 = n; }
    if (n < min1) { min2 = min1; min1 = n; }
    else if (n < min2) { min2 = n; }
}
return Math.max(max1 * max2, min1 * min2);
```

- **Время O(n)**, **память O(1)** — один проход, несколько переменных.
- Сортировка тоже работает (`Math.max(nums[0]*nums[1], nums[n-1]*nums[n-2])` после
  сортировки), но это **O(n log n)** — нормально для малых входов, медленнее на
  больших.

## Ответ на собеседовании (за 60 секунд)

> Наибольшее произведение двух чисел — это бо́льшее из (произведения двух самых
> больших) и (произведения двух самых маленьких), потому что два больших
> отрицательных дают большое положительное. Я отслеживаю эти четыре числа за один
> проход O(n) с памятью O(1) и возвращаю максимум из двух кандидатов. Сортировка
> тоже сработает, но стоит O(n log n).

## Частые заблуждения

- ❌ «Просто перемножь два наибольших.» — Пропускаешь случай двух отрицательных.
- ❌ «Сначала нужно отсортировать.» — Сортировка O(n log n); хватает одного
  линейного прохода.
- ❌ «Возьми модули.» — Так можно выбрать пару отрицательное × положительное и
  ошибиться со знаком; сравнивайте сами произведения-кандидаты.
